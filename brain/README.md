# brain — インシデント報告書の置き場（センターブレイン・このプロジェクト固有分）

**2層構造の片方**: 別プロジェクトでも再発しうる共通事例は `~/.claude/brain/`（README あり）、
このリポジトリの画面・演出・鑑定テキスト・デプロイでしか起きないものがここ。迷ったら
「リポジトリ名を伏せて読んでも意味が通るか」——通るなら共通側へ。

**トラブル・不具合・原因不明のエラーに当たったら、作業を始める前にまず `INDEX.md` を読む。**
症状が一致する行があればその報告書だけを開く。無ければ普通に調査し、**解決したら
`reports/NN_短い名前.md` を書いて還す**（書式は `~/.claude/brain/TEMPLATE.md`、30行以内、症状→原因→対処）。
`INDEX.md` に1行足すこと。同じ症状を再び踏んだら新規作成ではなく既存へ「再発: 日付」を追記する。

**作業の着手時は `APPROACHES.md`（作業の型、値つき）を作業の言葉で grep し、`PREMISES.md`（決定・環境の癖・未決）を読む。**
型は中央 `~/.claude/brain/APPROACHES.md` にあり、ここには**このアプリの値**だけを置く（2026-09-11 に配線）。
