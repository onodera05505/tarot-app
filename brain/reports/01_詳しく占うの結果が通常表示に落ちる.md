# 01. 詳しく占うの結果画面に通常の解説文しか出ない

- **日付/場所**: 2026-08-21（ユーザーの実機報告）/ `frontend/src/pages/ShufflePage.tsx`
- **症状**: `/deep` のカテゴリ選択と質問3問は正常に進むのに、結果画面には
  カード連動のベース解釈・回答別補足ではなく**通常の解説文**が出る。
  テスト（当時51件）は全緑、lint・ビルドも緑。
- **原因**: 儀式のストップ処理 `handleStop` が `reset()` を呼んでおり、
  フェーズ②で reset の対象に加えた `store.deep`（カテゴリ + 回答）まで消していた。
  deep が null になるため ResultPage が仕様どおり通常表示へフォールバックしていた。
- **対処**: `handleStop` から `reset()` を削除（`drawn`/`status`/`error` は
  `drawOne()` が上書きするので元々不要だった）。
  「ここで reset を呼んではいけない」を `ShufflePage.tsx:310` に現場コメントで残した。
- **すり抜けた理由**: 質問フローのテストは `/shuffle` をスタブにしており、
  **本物の handleStop を通る経路がテストに1本も無かった**。
- **再発防止**: 仕様 v3.1 §5.7 を根拠に、**本物の ShufflePage** でストップを押しても
  deep が保持されることを検証する回帰テストを `tests/components/ShufflePage.test.tsx` に追加。
  画面をまたぐ機能は「本物同士を繋いだ経路」を最低1本入れる方針にした
  （一般則としては共通側の報告書も参照）。
- **詳細**: [`history/2026-08-21.md`](../../history/2026-08-21.md) の 11.、コミット `8815624`
- **検索語**: deep, reset, handleStop, フォールバック, 詳しく占う, スタブ境界
