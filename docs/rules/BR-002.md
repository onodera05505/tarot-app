# BR-002 占いを始める・詳しく占うや儀式へ直接到達する・もう一度占う・占い結果でトップへ戻るときは占い状態を初期化する

スタート、詳しく占うを始める、詳しく占うへの直接到達、儀式への直接到達（スタートも持ち込む操作も経ずに儀式へ到達すること。占い結果からのブラウザの戻るを含む）、占い履歴から占いを始める（履歴なしの表示から儀式を始めること）、もう一度占う、占い結果でトップへ戻るのいずれでも、占い状態を idle に戻し、前の占い結果と詳しく占うの回答を引き継がない。儀式に入ること自体で初期化しないのは、スタートまたは持ち込む操作から儀式へ進むときに限る（スタートの初期化はスタートの時点で済んでおり、持ち込んだカテゴリと回答はそのまま儀式へ渡る）。占い結果の外（占い履歴・カード解説）でトップへ戻ることでも初期化しない。

初期化後の値の SSOT は `frontend/src/store/useReadingStore.ts`（`reset` が戻す初期値）。

**意図**: 一回の占いを毎回まっさらな状態から始め、前回の結果や回答が次の占いに混ざらないようにする（GOAL-01・GOAL-02）。
