# BR-002 占いを始める・もう一度占う・占い結果でトップへ戻るときは占い状態を初期化する

スタート、詳しく占うを始める、もう一度占う、占い結果でトップへ戻るのいずれでも、占い状態を idle に戻し、前の占い結果と詳しく占うの回答を引き継がない。ただし儀式に入ること自体では初期化しない（詳しく占うの回答はそのまま儀式へ持ち込む）。占い結果の外（占い履歴・カード解説）でトップへ戻ることでも初期化しない。

初期化後の値の SSOT は `frontend/src/store/useReadingStore.ts`（`reset` が戻す初期値）。

**意図**: 一回の占いを毎回まっさらな状態から始め、前回の結果や回答が次の占いに混ざらないようにする（GOAL-01・GOAL-02）。
