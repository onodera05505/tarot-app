# BR-005 無料版では詳しく占うを出さず、予告表示もしない

無料版では、詳しく占うの入口も、詳しく占うの画面も、カテゴリに沿った占い結果も示さない。あわせて、トップ・占い結果・占い履歴のどの画面にも予告表示をしない。Web とネイティブのアプリで同じ構成にする。

詳しく占うを出すかどうかの値の SSOT は `frontend/src/lib/features.ts`（`DEEP_READING_ENABLED`）。予告表示とみなす語の並びの機械可読な置き場は `frontend/tests/components/FreeRelease.test.tsx`（`TEASER_PATTERNS`）にしか無い。

**意図**: 初回の公開を無料・広告なしで出し、のちの買い切りで開放する価値を残す。審査で未完成と見なされる余地を作らない（仕様書 v3 §3.3）。
