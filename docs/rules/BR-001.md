# BR-001 抽選は完全ランダムで、占う人の操作と回答は結果に影響しない

抽選はカードも正逆も完全ランダムに決める。儀式の操作（山の順・山の選択・左右選択）と、詳しく占うの回答は、カードにも正逆にも影響しない。回答が決めるのは示す文章の選択だけである。本日の一枚の抽選も同じ決まりに従う。

正逆の出る割合の値の SSOT は `frontend/src/lib/api.ts`（`drawCards`）。

**意図**: 結果を演出でなく偶然に委ね、儀式は納得感をつくる演出に徹する（KPI-02・KPI-03、GOAL-01・GOAL-02）。占う人の操作で結果が動く方式は本人の要望で撤回済みで、覆すときはその経緯（仕様書 v3 §4.2）を読んでから。
