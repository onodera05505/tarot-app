# BR-004 占い履歴には結果の確定ごとの占い結果だけを記録し、本日の一枚は含めない

占い結果は、通常占いでも詳しく占うでも、結果の確定のたびに占う人の操作なしで占い履歴の先頭へ記録する。詳しく占うの占い結果にはカテゴリ名を添える。本日の一枚の開封は占い履歴に記録しない。

**意図**: 占う人が過去の占いを漏れなく振り返れるようにし、1 日 1 回の本日の一枚を占いと混ぜない（GOAL-05・GOAL-03）。
