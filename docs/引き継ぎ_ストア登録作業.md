# 引き継ぎ書: App Store 公開に向けた登録作業

作成: 2026-08-22。この文書は「アカウント登録・契約まわり」を担当する
別エージェント／別セッションへの引き継ぎ用。アプリ実装・リポジトリ操作は
開発側（別セッション）が担当するため、この文書の範囲では扱わない。

## 1. プロジェクト概要（30 秒版）

- 個人開発のタロット占いアプリ（Web アプリ、React 製）。占い演出と
  1,200 本超の鑑定テキストを持ち、機能面は完成済み・本番稼働中
- 本番: https://tarot-oracle-3qs.pages.dev （Cloudflare Pages、PWA 配信中）
- これを **Capacitor でラップして iOS ネイティブアプリ化し、Apple App Store に
  公開**する。Android/Google Play は後回し（iOS 先行）
- 収益化: **¥120 買い切り IAP**（「詳しく占う」の開放 + 広告消し）+ **広告**
  （バナー + インタースティシャル）。少額でも赤字にならない運用が勝利条件。
  **ただし初回申請は無料・広告なし・課金なし**（2026-09-02 決定）。収益化は
  次の更新で入れるので、下表の ②③④ は初回申請には不要

## 2. アカウント方針（最重要）

**個人開発の資産はすべて「個人アカウント」に統一する。社用と混ぜない。**

- 個人系の基準メール: `onodera.development@gmail.com`
  （Cloudflare・GitHub 等の既存インフラはこの個人系に集約済み）
- 社用のメール・Apple ID・Google アカウントは
  **一切使わない**。ログイン中のブラウザセッションが社用になっていないか、
  登録のたびに確認すること（過去にこの取り違えで認証トラブルが起きている）

## 3. 登録・契約する対象（この引き継ぎの本題）

優先順。①がクリティカルパス（承認待ちが発生するため最初に着手）。

| # | サービス | 目的 | 要点 |
|---|---|---|---|
| ① | **Apple Developer Program** | ストア公開の前提 | 個人として加入。年会費 約 1.5 万円（申込画面で最新額確認）。承認まで最大 48h |
| ② | **App Store Connect の契約類** | IAP 販売の前提 | Paid Applications 契約に同意 + 銀行口座 + 税務情報の登録。①の直後に |
| ③ | **AdMob**（Google） | 広告収益 | 個人系 Google アカウントで開設。**広告は非パーソナライズ運用の方針**（トラッキング許可ダイアログを出さないため）。アプリ登録・広告ユニット作成はアプリ実体ができてからでよい |
| ④ | **RevenueCat** | IAP の管理（推奨、任意） | 無料枠で開始。③同様、プロジェクト設定はアプリ実体の後でよい |

## 4. 決定済み事項（登録フォームで使う情報）

- アプリ名: **タロットカード** / サブタイトル: **手軽に本格占い**
- カテゴリ: エンターテインメント / 年齢区分: 4+
- 価格: アプリ本体は無料。初回申請では App 内課金なし（次の更新で ¥120 非消耗型を 1 つ追加予定）
- プライバシーポリシー等の公開 URL: 開発側が本番サイト配下に用意予定
  （文面も開発側が下書きする。登録時点で未公開なら「準備中」でよい）

## 5. 未確定・開発側との同期が必要な事項

以下は**勝手に確定させず**、決める前に開発側（ユーザー経由でよい）と同期する:

- **Bundle ID**（例案: `com.onodera.tarot`）— 後から変更しにくい。
  Capacitor 初期化と App Store Connect 登録で同一値を使う必要がある
- App Store Connect でのアプリ作成のタイミング（Capacitor 化の進行と同期）
- IAP の商品 ID 命名

## 6. 登録完了後に開発側へ引き渡すもの

- Apple Developer の **Team ID**（ビルド署名に必要）
- AdMob の **App ID と広告ユニット ID**（バナー用 / インタースティシャル用）
- RevenueCat を使う場合は **公開 API キー**
- ※ パスワード・秘密鍵・API シークレット類はチャットに貼らず、
  各サービスの画面上とパスワードマネージャで管理する

## 7. やらないこと（この引き継ぎの範囲外）

- リポジトリ・コード・CI の操作（開発側の担当）
- ストア素材（アイコン・スクリーンショット・説明文）の作成（開発側が下書き）
- 広告 SDK・IAP のアプリ側実装

疑問点が出たら、リポジトリ `docs/AppStore公開手順書.md` に全体像の詳細版がある。
