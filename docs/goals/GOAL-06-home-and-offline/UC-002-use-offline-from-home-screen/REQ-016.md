# REQ-016

> ネイティブのアプリとして動いている間、システムは通信の有無に依らず同梱の内容で開いて使えるようにする。

## 検証方針

- **分割クラス**:
  - `#native-offline` — ネイティブのアプリとして動いていて通信がすべて失敗する状態でも、開いて占い結果まで進める
  - `#native-online` — ネイティブのアプリとして動いていて通信がある状態でも、同梱の内容で開いて占い結果まで進める（通信の有無で振る舞いが変わらない）
- **尽きている根拠**: 要件の文は「通信の有無に依らず」と言うので、入力は通信あり・なしの 2 値で尽きる。ネイティブかどうかは契約の isNativePlatform の 2 値で、ネイティブでない側は REQ-013・REQ-014 が持つ。
- **検証しない**: 内容が実際にネイティブのアプリへ同梱されること（ビルドと同期の手順の結果）と、ネイティブの実行環境での動作。APK が未ビルドで、実機でしか確かめられないため。
- **参照先**: 未配置（この要件を観測する既存のテストは無い）
