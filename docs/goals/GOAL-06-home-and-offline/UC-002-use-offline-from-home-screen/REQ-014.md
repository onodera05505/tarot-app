# REQ-014

> 端末に保持済みのアプリを通信のない状態でブラウザまたはホーム画面から開いた場合でも、システムはアプリを開き、カードの画像を含む占い結果まで示して占えるようにする。

## 検証方針

- **分割クラス**:
  - `#reads-without-network` — 保持済みのアプリで、通信がすべて失敗する状態でも、占いを始めてカードの画像を含む占い結果まで進める
  - `#card-images-retained` — 保持の対象に、占い結果が使うすべてのカードの画像が含まれる
- **尽きている根拠**: 「通信なしで占える」は、占いの進行が通信に依らないこと（`#reads-without-network`）と、占い結果が使う画像が保持の対象に入っていること（`#card-images-retained`）の積で成り立ち、どちらか一方が欠ければ要件の文は偽になる。
- **検証しない**: ブラウザから開くかホーム画面から開くかという入口の違い（ホーム画面から開く経路は端末の OS が担い、実機でしか再現できない）。保持した内容から実際に通信なしで画面が開くこと（本物のブラウザの保持の仕組みが要る）。端末に保持した内容が端末側の都合で消された場合（例外系の走査で `?`、振る舞いが決まっていない）。
- **参照先**: 未配置（この要件を観測する既存のテストは無い）
