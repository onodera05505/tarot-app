# REQ-015

> 占う人が端末に保持済みのアプリをホーム画面に追加したとき、アプリはアプリ名とアイコンでホーム画面に置かれ、以後そこから開くとブラウザの操作枠なしで開く。

- **分割クラス**:
  - `#declares-name-and-icon` — ホーム画面に置くための宣言が、アプリ名とアイコンを持つ
  - `#declares-no-browser-frame` — ホーム画面に置くための宣言が、ブラウザの操作枠なしで開く表示を指定する
- **尽きている根拠**: 要件の文の観測点は「アプリ名とアイコンで置かれる」と「操作枠なしで開く」の 2 つで、どちらもアプリ側では宣言としてだけ現れる（置く操作と開き方の解釈は端末側）。
- **検証しない**: 実際にホーム画面に置かれる見た目と、そこから操作枠なしで開くこと。宣言の解釈は端末の OS とブラウザが行い、実機でしか確かめられないため。
- **参照先**: 未配置（この要件を観測する既存のテストは無い）
