# UC-002 ホーム画面から開いて通信なしで占う

## 概要

占う人が、一度ブラウザで開いたアプリをホーム画面に置き、通信がない場所でもそこから開いて占う。

## 事前条件

- 占う人がブラウザで一度、通信のある状態でアプリを開いている
- そのブラウザが保持の仕組みを登録できる
- 適用される業務規則: BR-006

## 主シナリオ

1. 占う人が通信のある状態でブラウザからアプリを開く
2. システムがアプリを表示し、以後通信なしでも開けるように全体を端末に保持する
3. 占う人がアプリをホーム画面に追加する
4. システムがアプリ名とアイコンでホーム画面に置かれる
5. 占う人が通信のない状態でホーム画面からアプリを開く
6. システムがブラウザの操作枠なしでアプリを開く
7. 占う人が占いを行う
8. システムがカードの画像を含む占い結果を示す

- 失敗時: いかなる状態変更も残っていない（部分適用なし）
