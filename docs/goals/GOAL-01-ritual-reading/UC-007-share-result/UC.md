# UC-007 占い結果をシェアする

## 概要

占う人が、いま読んでいる占い結果を画像にして、端末の共有機能から他のアプリへ渡す。共有機能が使えないときは端末への保存が代わりに受け取る。

## 事前条件

- 適用される業務規則: なし（BR は未抽出。決まりの候補は本文の BR候補 の印）
- 占い結果が表示されている（UC-006 の成功時）。

## 主シナリオ

1. 占う人が占い結果のシェアを選ぶ。
2. システムが、カード画像・カード名・正逆・キーワードを載せたシェア画像を作る。<!-- BR候補: 逆位置のカードは画像を上下逆さに見せる（結果・拡大・シェア画像・カード解説で共通） -->
3. システムがシェア画像に、カード名と正逆を添えて端末の共有機能へ渡す。
4. 端末の共有機能がシェア画像を受け取り、占う人が選んだ他のアプリへ渡す。
5. システムが、再びシェアを選べる状態に戻る。
