# REQ-072

> 占う人が占い結果のシェアを選んだとき、端末の共有機能がシェア画像を受け取れるなら、システムはその占い結果のカード画像・カード名・正逆・キーワードを載せたシェア画像を作り、カード名と正逆を添えて端末の共有機能へ渡す。

- **分割クラス**:
  - `#upright-share` — 正位置の占い結果のシェアで、その占い結果からシェア画像を作り、カード名と「正位置」を添えて共有機能へ渡す
  - `#reversed-share` — 逆位置の占い結果のシェアで、添える文が「逆位置」になる
- **尽きている根拠**: シェアの中身を変える入力は正逆の 2 値で、カードの違いは作る画像と添える文がデータ由来であることで代表させる。
- **検証しない**: シェア画像に実際に描かれる内容（カード画像・文字・逆位置の画像の向き）は Canvas の描画で jsdom に無く、実機・実ブラウザで見る。端末の共有機能そのものの受け取りも実機で見る。
