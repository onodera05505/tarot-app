# REQ-067

> 抽選に失敗して占い状態が error である間、システムは占い結果を開いた占う人にカードを引けなかったことを示し、トップへ戻る以外の操作を示さない。

- **分割クラス**:
  - `#failure-shown` — 占い状態が error の占い結果ではカードを引けなかったことを示し、トップへ戻る以外の操作を示さない
- **尽きている根拠**: 失敗の原因によらず占い状態は error の 1 つにまとまり、示し方は同じ。占い結果への入り方（儀式の左右選択から・儀式の外から開く）の違いは、占い結果の側から見て占い状態 error の 1 点に集まる。
- **検証しない**: 失敗の原因の種類ごとの違い（原因によらず同じ示し方なので代表 1 つ）。示す文言そのものは要件にしない。
