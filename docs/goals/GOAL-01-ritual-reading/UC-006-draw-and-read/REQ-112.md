# REQ-112

> 儀式が左右選択を待つ段階にある間、システムは占い状態が drawing のときに限りカードを引いている途中であることを示す。

## 検証方針

- **分割クラス**:
  - `#pending-shows-drawing` — 左右選択を待つ段階で占い状態が drawing（抽選がまだ終わっていない）の間、カードを引いている途中であることを示す
  - `#failed-not-shown` — 左右選択を待つ段階で占い状態が error（抽選に失敗した）のときは、カードを引いている途中であることを示さない
  - `#result-present-not-shown` — 左右選択を待つ段階で占い状態が drawn（占い結果がある）のときは、カードを引いている途中であることを示さない
- **尽きている根拠**: 文の条件は占い状態で、左右選択を待つ段階で取りうる占い状態は drawing / drawn / error の 3 つに尽きる（UC-006 の表の orienting × 抽選の完了・抽選の失敗。idle はストップを経ずに左右選択の段階へ着けないので外から作れない）。示す側は drawing の 1 つ、示さない側は drawn と error の 2 つで、示さない理由が違うので分ける。
- **検証しない**: 示す文言そのものは要件にしない。左右選択を待つ段階のあいだに抽選が完了・失敗して表示が消える、その切り替わりの瞬間は見ない（完了・失敗の前と後の 2 点で代表させる）。占い状態が idle のまま左右選択を待つ段階にある場合（外から作れない）。
