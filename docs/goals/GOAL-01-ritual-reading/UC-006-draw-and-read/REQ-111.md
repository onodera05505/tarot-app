# REQ-111

> 儀式が山の指定を待つ段階にある間、システムは 3 つの山では順を指定済みの山それぞれに何番目かを示し、2 つの山では選ばれている山を示す。

## 検証方針

- **分割クラス**:
  - `#split3-order-shown` — 3 つの山で、順を指定済みの山それぞれに何番目かが示され、未指定の山には示されない
  - `#split2-selection-shown` — 2 つの山で、選ばれている山だけに選ばれていることが示される
- **尽きている根拠**: 山の指定を待つ段階は 3 つの山と 2 つの山の 2 つで尽きる。3 つの山は指定済みの数 0〜3 を順にたどり、2 つの山は選ぶ山の 2 値を両方見る。
- **境界の扱い**: `#split3-order-shown` は指定済みが 0（何も示さない）から 3（すべてに示す）まで。
- **検証しない**: 示し方の見た目（位置・色・大きさ）は実機で見る。2 つの山で片方を選んだまま他方を選んだときの扱いは、どの要件の文も定めていないのでクラスにしない。
