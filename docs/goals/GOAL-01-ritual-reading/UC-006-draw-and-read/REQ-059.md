# REQ-059

> 3 つの山すべてに積み上げる順を指定する前に決定が選ばれた場合、システムは儀式を先へ進めず、積み上げる順の指定を待ち続ける。

## 検証方針

- **分割クラス**:
  - `#none-specified` — 1 つの山にも順を指定せずに決定しても先へ進まない
  - `#partially-specified` — 一部の山だけに順を指定して決定しても先へ進まず、順の指定を待ち続ける
- **尽きている根拠**: 指定済みの山の数は 0〜3 で、3 は REQ-060 の持ち分。0 と 1〜2 を分ける。
- **境界の扱い**: `#partially-specified` の境界は指定済み 1 と 2 の両端。
- **検証しない**: 無し。
