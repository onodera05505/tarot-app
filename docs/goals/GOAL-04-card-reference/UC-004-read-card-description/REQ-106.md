# REQ-106

> 実在するカードのカード解説を示しているときに占う人が戻ることを選んだとき、直前に示していた画面があるなら、システムはその画面を示す。

- **分割クラス**:
  - `#back-to-previous` — 実在するカードのカード解説で戻ることを選ぶと、直前に示していた画面が示される
- **尽きている根拠**: 直前に示していた画面がある場合の振る舞いは、その画面が何であっても「その画面を示す」の一通りなので 1 クラス。行き先を一覧に決め打ちする誤りを見分けるため、直前の画面が一覧である入力と一覧でない入力（占い履歴）をどちらもテストで通す
- **検証しない**: 直前に示していた画面が無い場合（UC-004 の表の ? 。望む振る舞いが未決のため）。本物のブラウザの戻る・進むの履歴（jsdom では画面の履歴をテストの側で用意して代える）
