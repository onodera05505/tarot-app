# REQ-107

> カード解説の一覧、または 1 枚のカードのカード解説のためにカードの内容を読み込んでいる間、システムは読み込み中であることを示す。

- **分割クラス**:
  - `#list-loading` — カード解説の一覧のためにカードの内容を読み込んでいる間、読み込み中であることが示される
  - `#detail-loading` — 1 枚のカードのカード解説のためにカードの内容を読み込んでいる間、読み込み中であることが示される
- **尽きている根拠**: カードの内容を読み込むのは「一覧」と「1 枚のカード解説」の 2 つに尽きる。1 枚のカード解説では、指定がカードに当たるかどうかは読み込み終えるまで決まらないので、実在するカードと存在しないカードの行は読み込んでいる間は同じ入力として 1 クラスにまとめる。数に読めない指定は読み込む前に退けられる（UC-004 の表で不可）
- **検証しない**: 読み込み中を示す文言の言い回しと見た目（用語集の語「読み込み中」が示されることだけを見る）。読み込みに掛かる時間（カードの内容はアプリに含まれ、実際にはごく短い）
- **参照先**: `frontend/tests/components/CardListPage.test.tsx::カード解説一覧: 見出しと読み込み中（§5.5）`、`frontend/tests/components/CardDetailPage.test.tsx::カード解説詳細: 実在する id の表示（§5.5「カード画像・名前・正逆それぞれのキーワードと解説文」）`
