  - `#reversed` — 逆位置の指定で開くと、カードが上下逆さに示され、逆位置の節が先に、正位置の節も続けて示される
  - `#upright` — 正位置の指定で開くと、カードが正しい向きで示され、正位置の節が先に、逆位置の節も続けて示される
- **尽きている根拠**: 指定できる正逆は 2 値に尽きる
