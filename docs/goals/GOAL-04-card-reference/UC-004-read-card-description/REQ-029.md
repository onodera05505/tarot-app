# REQ-029

> カード解説が、実在するカードをカードの識別番号で指し、正位置または逆位置の指定で開かれたとき、システムはそのカードのカード名と指定された正逆の向きのカード、正位置と逆位置それぞれのキーワードと解説文を、指定された正逆を先にして示す。

- **分割クラス**:
  - `#reversed` — 実在するカードを逆位置の指定で開くと、そのカードのカード名が示され、カードが上下逆さに示され、逆位置の節が先に、正位置の節も続けて示される
  - `#upright` — 実在するカードを正位置の指定で開くと、そのカードのカード名が示され、カードが正しい向きで示され、正位置の節が先に、逆位置の節も続けて示される
- **尽きている根拠**: 指定できる正逆は 2 値に尽きる。どちらとも読めない指定と指定なしは REQ-028 に、実在しないカード・形の不正な指定は REQ-030・REQ-031 に分けてある。カード名はどちらの指定でも同じように示すので、クラスを分けずに両方のクラスで見る
- **検証しない**: 絵の見た目そのもの（実ブラウザでしか確かめられない。jsdom では向きの指定だけを見る）。カード名の英名の併記（用語集はカード解説で英名も併せて示すとするが、要件の文が求めるのはカード名で、既存のテストは和名で見ている）
