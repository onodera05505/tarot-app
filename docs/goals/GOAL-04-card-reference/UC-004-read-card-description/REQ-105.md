- **分割クラス**:
  - `#from-list` — カード解説の一覧でトップへ戻ることを選ぶと、トップが示される
  - `#from-detail` — 実在するカードのカード解説でトップへ戻ることを選ぶと、直前に示していた画面ではなくトップが示される
- **尽きている根拠**: トップへ戻る操作を出す状態は「一覧」と「実在するカードのカード解説」の 2 つに尽きる（UC-004 の表で、見つからない・不正を示しているときは一覧へ戻る操作だけを出すので不可）
- **検証しない**: トップの中身（トップの側の要件が持つため。ここではトップへ移ることだけを見る）。カードの内容を読み込んでいる間にトップへ戻る場合（表に無い組み合わせのため）
