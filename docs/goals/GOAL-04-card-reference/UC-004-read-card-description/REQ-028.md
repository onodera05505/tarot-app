# REQ-028

> カード解説が、実在するカードをカードの識別番号で指し、正逆の指定なし、または正位置とも逆位置とも読めない正逆の指定で開かれたとき、システムはそのカードのカード名と正しい向きのカード、正位置と逆位置それぞれのキーワードと解説文を、正位置を先にして示す。

## 検証方針

- **分割クラス**:
  - `#no-orientation` — 正逆の指定なしで開くと、そのカードだけのカード名・正しい向きのカード・正逆それぞれのキーワードと解説文が、正位置を先にして示される
  - `#invalid-orientation` — 正位置とも逆位置とも読めない正逆の指定で開くと、指定なしと同じく正しい向き・正位置を先にして示される
- **尽きている根拠**: 正逆の指定は「なし」「正位置」「逆位置」「どちらとも読めない値」に尽き、正位置・逆位置の指定は REQ-029 に分けてある
- **境界の扱い**: どちらとも読めない値のうち、空の値と大文字小文字だけ違う値は既存のテストが見ていない
- **検証しない**: 解説文の内容そのものの良し悪し（内容の生成 UC-010 の側の検証のため）
