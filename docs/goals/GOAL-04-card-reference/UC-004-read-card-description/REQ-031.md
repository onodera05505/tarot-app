# REQ-031

> カード解説が、カードの識別番号として数に読めない指定で開かれたとき、システムは正逆の指定にかかわらず、カードの指定が不正であることを示し、どのカードのカード名も解説文も示さない。

## 検証方針

- **分割クラス**:
  - `#malformed-without-orientation` — カードの識別番号として数に読めない指定を正逆の指定なしで開くと、カードの指定が不正であることが示され、どのカードのカード名も解説文も示されない
  - `#malformed-with-orientation` — 数に読めない指定は、正逆の指定（正位置・逆位置・どちらとも読めない値）があっても、同じく不正であることが示され、どのカードも示されない
- **尽きている根拠**: 要件の文が「正逆の指定にかかわらず」と言うので、正逆の指定の有無で分ける。数には読めるがどのカードにも当たらない指定は REQ-030 に分けてある
- **検証しない**: 数字と文字が混ざった指定や空白だけの指定（「数に読めない」に含めるかを要件の文が定めていないため。テストは数字を含まない語で代表させる）
