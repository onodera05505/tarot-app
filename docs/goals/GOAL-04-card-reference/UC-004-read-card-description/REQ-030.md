# REQ-030

> カード解説が、カードの識別番号として数には読めるがどのカードにも当たらない指定で開かれたとき、システムは正逆の指定にかかわらず、カードが見つからないことを示し、どのカードのカード名も解説文も示さない。

## 検証方針

- **分割クラス**:
  - `#nonexistent-id` — 数には読めるがどのカードにも当たらない指定を正逆の指定なしで開くと、カードが見つからないことが示され、どのカードのカード名も解説文も示されない
  - `#nonexistent-with-orientation` — どのカードにも当たらない指定は、正逆の指定（正位置・逆位置・どちらとも読めない値）があっても、同じく見つからないことが示され、どのカードも示されない
- **尽きている根拠**: 要件の文が「正逆の指定にかかわらず」と言い、UC-004 の表も正逆の指定の 3 列すべてにこの要件を当てているので、正逆の指定の有無で分ける。数に読めない指定は REQ-031 に分けてある
- **境界の扱い**: 実在する最大の識別番号の次、0、負の数が境界点で、どれも「数には読めるがどのカードにも当たらない」側（見つからない）
- **検証しない**: 小数や指数表記など、整数でない数の形の指定（「識別番号として数に読める」に含めるかを要件の文が定めていないため）
