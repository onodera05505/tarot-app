# REQ-030

> カード解説が、カードの識別番号として数には読めるがどのカードにも当たらない指定で開かれたとき、システムは正逆の指定にかかわらず、カードが見つからないことを示し、どのカードのカード名も解説文も示さない。

- **分割クラス**:
  - `#nonexistent-id` — カードを指す形をしているがどのカードにも当たらない指定で開くと、カードが見つからないことが示され、どのカードのカード名も解説文も示されない
- **尽きている根拠**: どのカードにも当たらない指定は、正逆の指定の有無によらず同じ振る舞いなので 1 クラス
- **境界の扱い**: 実在する最大の番号の次が境界点。0 や負の数が「見つからない」と「不正」のどちらに当たるかは要件の文が定めていない
- **検証しない**: 無し
- **参照先**: `frontend/tests/components/CardDetailPage.test.tsx::カード解説詳細: 不正な id・存在しない id`、`frontend/tests/api.test.ts::fetchCard`
