# UC-004 カード解説を読む

## 概要

占う人が、占いとは別に 22 枚のカードから 1 枚を選び、その正位置・逆位置それぞれのキーワードと解説文を読む。正逆を指定して開いたときは、指定した正逆から読める。

## 事前条件

- なし（認証は無く、カードの内容はアプリに含まれている）
- 適用される業務規則: BR-003

## 主シナリオ

1. 占う人がカード解説を開く
2. システムが大アルカナ 22 枚を、アルカナ番号順に、カードの表・カード名・アルカナ番号・正位置のキーワードを添えて示す
3. 占う人が 1 枚のカードを選ぶ
4. システムがそのカードのカード名とカード、正位置と逆位置それぞれのキーワードと解説文を、正位置を先にして示す
