# REQ-026

> 占う人がカード解説を開いたとき、システムは大アルカナのすべてのカードを、アルカナ番号順に、それぞれのカードの表・カード名・アルカナ番号・正位置のキーワードを添えて示す。

- **分割クラス**:
  - `#numbered-order` — 大アルカナのすべてのカードが、過不足なくアルカナ番号順に並ぶ
  - `#name-and-number` — 各カードにそのカードのカード名とアルカナ番号が添えられる
  - `#upright-keywords` — 各カードにそのカードの正位置のキーワードが添えられる
  - `#card-shown` — 各カードにそのカードの表が添えられる
- **尽きている根拠**: 一覧の観測は「並び（と枚数）」と「各カードに添えるもの（カードの表・カード名・アルカナ番号・正位置のキーワード）」に尽きる。添えるものはそれぞれ単独で欠けうるので分ける。カードの内容はアプリに含まれ、読み込みの失敗は外から起こせない（UC-004 の表の「カードデータを読めない」列は不可）。読み込んでいる間は REQ-107 に分けてある
- **検証しない**: アルカナ番号の表記の桁数（要件の文が表記を定めていないため。既存のテストは 2 桁のゼロ埋めで見ている）。逆位置のキーワードを一覧に示さないこと（要件の文は添えるものだけを定めているため）。カードの表の絵の見た目そのもの（実ブラウザでしか確かめられない。jsdom ではそのカードの絵が置かれていることだけを見る）
