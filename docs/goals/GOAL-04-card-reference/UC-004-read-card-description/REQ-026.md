- **分割クラス**:
  - `#numbered-order` — 大アルカナのすべてのカードが、過不足なくアルカナ番号順に並ぶ
  - `#name-and-number` — 各カードにそのカードのカード名とアルカナ番号が添えられる
  - `#card-shown` — 各カードにそのカードの絵が示される
- **尽きている根拠**: 一覧の観測は「並び（と枚数）」と「各カードに添えるもの（カード名・アルカナ番号・絵）」に尽きる。カードの内容はアプリに含まれ、読み込みの失敗は外から起こせない（REQ-033 は取り下げ）
- **検証しない**: アルカナ番号の表記の桁数（要件の文が表記を定めていないため。既存のテストは 2 桁のゼロ埋めで見ている）
- **参照先**: `frontend/tests/components/CardListPage.test.tsx::カード解説一覧: 22 枚を番号順に表示（§5.5）`、`frontend/tests/api.test.ts::fetchAllCards`
