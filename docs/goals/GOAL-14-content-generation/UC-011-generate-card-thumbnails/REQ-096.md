# REQ-096

> 運営者がサムネイルを生成したとき、システムはどのカードも指さないものを含むすべての原本を縦横比を保って決められた幅に縮小したサムネイルを書き出し、書き出し先にあるサムネイルの枚数と縮小前後の合計容量を示す。

- **分割クラス**:
  - `#all-originals-thumbnailed` — どのカードも指さない原本を含むすべての原本からサムネイルが書き出される
  - `#aspect-width` — サムネイルが縦横比を保って決められた幅に縮小されている
  - `#report-count-size` — 書き出し先にあるサムネイルの枚数と縮小前後の合計容量を示す
- **尽きている根拠**: 文が述べる観測は対象（すべての原本）・形（縦横比と幅）・示す内容の 3 つで、互いに独立に壊れうる
- **検証しない**: サムネイルの画質・見た目（目視でしか判断できない）。生成は開発機の画像処理の道具に頼り CI では再生成できない（ADR-0007）ため、現在は既存のテストが無く全クラス未被覆
- **参照先**: なし（既存のテスト無し。サムネイルの実在は REQ-097 が見る）
