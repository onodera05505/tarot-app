# REQ-097

> 運営者が検査を実行したとき、システムはカードと裏面のすべてに原本とサムネイルがあることを確かめ、すべてあるときに限り検査を通し、無いものがあれば無いものを示す。

## 検証方針

- **分割クラス**:
  - `#original-missing` — カード（22 枚）か裏面のいずれかの原本が無いとき、検査を通さず無いものを示す
  - `#thumb-missing` — カード（22 枚）か裏面のいずれかのサムネイルが無いとき、検査を通さず無いものを示す
- **尽きている根拠**: 文の条件は対象（カード・裏面）× 種類（原本・サムネイル）。テストは対象をすべてなめて無いものを並べるので、対象ではなく種類でクラスを割った
- **検証しない**: どのカードも指さない原本・サムネイルが余分にあること（文の対象外。OQ-29-4）。原本とサムネイルの中身の対応（原本を差し替えてサムネイルを生成し直し忘れた状態）は実在しか見ないため拾わない（ADR-0007、OQ-29-2）
- **参照先**: `frontend/tests/cards-data.test.ts::カードデータ（仕様書 v3 §4.1）`、`frontend/tests/card-back.test.ts::カード裏面画像の集約`、`frontend/tests/card-thumbs.test.ts::カード画像のサムネイル`
