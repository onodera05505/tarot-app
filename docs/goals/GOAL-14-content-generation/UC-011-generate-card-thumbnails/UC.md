# UC-011 カード画像の原本を差し替えてサムネイルを生成する

## 概要

運営者がカードや裏面の原本（カード画像）を差し替え、生成でサムネイルを作り直し、検査でカードと裏面のすべてに原本とサムネイルがあることを確かめる。

## 事前条件

- 適用される業務規則: なし
<!-- BR候補: 書式が崩れた編集元・原本からは生成物を作らない（UC-010 と共有） -->
<!-- BR候補: 生成物は手で編集しない（UC-010 と共有） -->

## 主シナリオ

1. 運営者が原本（カード画像）を差し替える
2. 運営者がサムネイルの生成を実行する
3. システムがすべての原本からサムネイルを書き出し、枚数と縮小前後の合計容量を示す
4. 運営者が検査を実行する
5. システムがカードと裏面のすべてに原本とサムネイルがあることを示す

## 事後条件

- 成功時: 運営者が、差し替えた原本から作られたサムネイルと、カードと裏面のすべてに原本とサムネイルがあるという検査の結果を見ている
- 失敗時: いかなる状態変更も残っていない（部分適用なし）
