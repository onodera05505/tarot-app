# REQ-090

> 運営者がカードの内容を生成したとき、システムはカードの編集元の内容でカードの生成物を書き出し直し、生成したカードの件数を示す。

## 検証方針

- **分割クラス**:
  - `#regenerate-from-source` — 生成物が編集元と食い違っていても（生成し忘れ・生成物を手で直した）、編集元の内容で書き出し直される
  - `#report-count` — 生成したカードの件数を示す
- **尽きている根拠**: 文が述べる観測は「生成物の中身が編集元に一致すること」と「件数を示すこと」の 2 つ。編集元が書式どおりである前提の下で、生成前の生成物の状態（編集元と一致・食い違い）は書き出し直しで同じ結果になるため 1 クラスにまとめる
- **検証しない**: なし（現在は既存のテストが無く、両クラスとも未被覆。生成スクリプトを小さな編集元で実行するテストは書ける）
- **参照先**: なし（既存のテスト無し）
