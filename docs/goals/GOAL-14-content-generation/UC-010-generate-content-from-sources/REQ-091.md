# REQ-091

> 運営者が詳しく占うの文章を生成したとき、システムはすべてのカテゴリの編集元から各カテゴリの生成物とカテゴリの一覧を書き出し直し、生成したカテゴリを示す。

- **分割クラス**:
  - `#all-categories-regenerated` — すべてのカテゴリの編集元から各カテゴリの生成物が書き出し直される（生成物の手直し・生成し忘れを含む）
  - `#category-list-regenerated` — カテゴリの一覧が編集元のカテゴリから書き出し直される
  - `#report-categories` — 生成したカテゴリを示す
- **尽きている根拠**: 文が述べる観測は各カテゴリの生成物・カテゴリの一覧・示す内容の 3 つで、互いに独立に壊れうる
