# REQ-092

> 運営者が検査を実行したとき、システムはカードと詳しく占うの生成物について、カードの枚数と番号の過不足・重複、必須の文章の欠け、カテゴリの重複、質問と選択肢の数、キーワードの語数とベース解釈・回答別アドバイス・回答別補足の字数が決められた範囲にあることを確かめ、すべて満たすときに限り検査を通す。

## 検証方針

- **分割クラス**:
  - `#card-count` — カードの生成物の枚数が決められた枚数である
  - `#card-number` — カードの番号（番号と識別子）に過不足・重複が無い
  - `#card-required-text` — カードの必須の文章に空やプレースホルダーが残っていない
  - `#keyword-word-count` — 正逆のキーワードの語数が決められた範囲にある
  - `#category-duplicate` — カテゴリの一覧で同じカテゴリが重複しない
  - `#deep-required-text` — 詳しく占うの必須の文章（カテゴリ名・質問文・選択肢・ベース解釈）が欠けていない
  - `#question-choice-count` — 各カテゴリの質問の数と各質問の選択肢の数が決められた数である
  - `#deep-card-number` — 詳しく占うのベース解釈がすべてのカード番号を過不足なく持つ
  - `#base-length` — ベース解釈の字数が決められた範囲にある
  - `#advice-length` — 回答別アドバイスの字数が決められた範囲にある
  - `#supplement-length` — 回答別補足の字数が決められた範囲にある
- **尽きている根拠**: 文が列挙する確かめる項目を、生成物（カード・詳しく占う）ごとに 1 クラスずつに割った。カードの「枚数と番号の過不足・重複」は枚数と番号で観測が異なるので分け、詳しく占うでは番号の過不足 1 つにまとめた
- **境界の扱い**: 「決められた範囲」は仕様の目安に執筆の揺れの許容を足した範囲で、値とその理由はテストが持つ
- **検証しない**: 検査が違反を見逃さないこと（壊した生成物を与えて検査が落ちること）は確かめない。検査はこのテスト群そのもので生成物の実物を読むため、検査の検査は持たず、各アサーションの意味はレビューで見る（R-901）
