# REQ-095

> カードの編集元で、どのカードの見出しの書式も崩れておらず決められた番号の外のカードも無いまま、カードの枚数が揃わないか必須の文章が空である場合、システムはその旨の警告を示したうえで、カードの生成物を書き出す。

## 検証方針

- **分割クラス**:
  - `#card-count-short` — どのカードの見出しの書式も崩れておらず決められた番号の外のカードも無いまま、カードの枚数が揃わない編集元で、警告を示して生成物を書き出す
  - `#required-text-empty` — どのカードの見出しの書式も崩れておらず決められた番号の外のカードも無いまま、必須の文章が空のカードがある編集元で、警告を示して生成物を書き出す
- **尽きている根拠**: 文の条件は「枚数が揃わない」と「必須の文章が空」の 2 つで、警告の内容が異なる。どちらも、見出しの書式の崩れと決められた番号の外のカードが無いことが前提で、それらを併せ持つ編集元は UC-010 の状態表の「構造が崩れている」の行に当たり、生成が失敗する側として REQ-121 が持つ
- **境界の扱い**: 必須の行や区切りが欠けた結果として枚数が揃わない・必須の文章が空になる編集元は、見出しの書式が崩れていないかぎりこの要件の側（状態表の行の注記）
- **検証しない**: 同じカードが重複しているカードの編集元と、分量が目安を外れているカードの編集元（状態表で `?`。振る舞いが決まっていないため）。現在は既存のテストが無く、両クラスとも未被覆（生成を実行すると実物の生成物が書き換わるため、書き出し先を実物から切り離す手段が決まるまで、生成を実行するテストは置いていない。この要件は取り下げの候補で OQ-29-1・OQ-31-2 が未決）
- **参照先**: なし（既存のテスト無し）
