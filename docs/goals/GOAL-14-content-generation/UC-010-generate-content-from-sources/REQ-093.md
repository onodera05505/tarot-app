# REQ-093

> 編集元の構造が崩れている場合、システムは生成を失敗させてその理由を示し、どの生成物も書き換えない。

- **分割クラス**:
  - `#card-structure-broken` — カードの編集元で見出し・必須の行・区切りが崩れている
  - `#deep-structure-broken` — 詳しく占うの編集元で見出し・必須の行・区切りが崩れている
  - `#deep-question-choice-count` — 詳しく占うの編集元で問いと選択肢の数が決められた数でない
  - `#deep-undefined-ref` — 詳しく占うの編集元が未定義のカテゴリや選択肢を指している
  - `#deep-card-missing-or-empty` — 詳しく占うの編集元でカードの枚数が揃わないか必須の文章が空である
  - `#deep-duplicate-card` — 詳しく占うの編集元で同じカードが重複している
  - `#deep-category-outside-set` — 詳しく占うの編集元が決められたカテゴリの集合の外のカテゴリを名乗っている
  - `#deep-advice-supplement-mixed` — 詳しく占うの編集元で回答別アドバイスと回答別補足がカテゴリの中で混在している、または回答別アドバイスが歯抜けになっている
- **尽きている根拠**: 状態 × イベント表で REQ-093 に当たる行（構造の崩れ・集合の外のカテゴリ・回答別アドバイスと回答別補足の混在と歯抜け・枚数と必須の文章・カードの重複）を、生成（カード・詳しく占う）ごとに割った。どのクラスでも「失敗して理由を示す」と「どの生成物も書き換えない」の両方を観測する
- **検証しない**: なし（現在は既存のテストが無く、全クラス未被覆）
- **参照先**: なし（既存のテスト無し）
