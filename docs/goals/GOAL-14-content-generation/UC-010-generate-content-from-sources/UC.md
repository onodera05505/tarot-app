# UC-010 編集元を直して内容を生成する

## 概要

運営者がカードの内容または詳しく占うの文章を編集元で直し、生成で書式を確かめたうえで生成物を作り、検査で生成物が揃っていることを確かめる。

## 事前条件

- 適用される業務規則: なし（書式の崩れ・ジャンル語の決まりはこの UC の中で閉じ、表の行が持つ）

## 主シナリオ

1. 運営者が編集元（カードの内容、または詳しく占うのカテゴリ）を直す
2. 運営者が生成を実行する
3. システムが編集元の書式を確かめる
4. システムが生成物を書き出し、生成した件数を示す
5. 運営者が検査を実行する
6. システムが生成物が揃っていることを示す

## 事後条件

- 成功時: 運営者が、直した編集元から作られた生成物と、それが揃っているという検査の結果を見ている
- 失敗時: いかなる状態変更も残っていない（部分適用なし。書式が崩れていれば生成物は前のまま）
