# REQ-121

> カードの編集元でカードの見出しの書式が崩れているか決められた番号の外のカードがある場合、システムはカードの内容の生成を失敗させてその理由を示し、どの生成物も書き換えない。

## 検証方針

- **分割クラス**:
  - `#card-heading-broken` — カードの編集元でカードの見出しの書式が崩れている
  - `#card-number-outside-set` — カードの編集元に決められた番号の外のカードがある
- **尽きている根拠**: 文の条件は 2 つの論理和で、壊し方が異なるので 1 つずつクラスにした。どちらのクラスでも「失敗して理由を示す」と「どの生成物も書き換えない」の両方を観測する。必須の行や区切りが欠けた結果としての枚数の不足・必須の文章の空は、生成が止まらない側で REQ-095 が持つ。
- **境界の扱い**: 決められた番号の端のすぐ外（最小の 1 つ下・最大の 1 つ上）が境界。
- **検証しない**: 同じカードが重複しているカードの編集元と、分量が目安を外れているカードの編集元は、UC-010 の状態表で `?`（振る舞いが決まっていない）のため。
- **参照先**: なし（既存のテスト無し。両クラスとも未被覆。生成を実行すると実物の生成物が書き換わるため、書き出し先を実物から切り離す手段が決まるまで、生成を実行するテストは置いていない）
