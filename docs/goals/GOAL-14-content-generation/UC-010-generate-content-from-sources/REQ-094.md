# REQ-094

> 詳しく占うの編集元でベース解釈の第一文にそのカテゴリのジャンル語が無い場合、システムは詳しく占うの文章の生成を失敗させて該当するカテゴリ・カード・正逆を示し、どの生成物も書き換えない。
