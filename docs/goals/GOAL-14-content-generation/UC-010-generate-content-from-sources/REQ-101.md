# REQ-101

> 運営者が検査を実行したときに、詳しく占うのあるカテゴリの生成物が、すべてのカードと選択肢の組に回答別アドバイスを持ち回答別補足を持たない形と、すべての選択肢に回答別補足を持ち回答別アドバイスを持たない形のどちらでもない場合、システムは検査を通さない。

## 検証方針

- **分割クラス**:
  - `#neither-form` — あるカテゴリの生成物が、回答別アドバイスだけの形（すべてのカードと選択肢の組に揃う）にも回答別補足だけの形（すべての選択肢に揃う）にもなっていない（歯抜け・混在）とき、検査を通さない
- **尽きている根拠**: 文の条件は許される 2 つの形の補集合で、歯抜けでも混在でも検査の結論（通さない）は同じなので 1 クラス。許される 2 つの形の側は、実物の生成物がどちらかの形で検査を通ることで同じテストが観測する
- **検証しない**: 検査が違反を見逃さないこと（歯抜けや混在の生成物を与えて検査が落ちること）は確かめない。検査はこのテスト群そのもので生成物の実物を読むため、検査の検査は持たない（REQ-092 と同じ理由。R-901）。回答別アドバイス・回答別補足の字数は REQ-092 の持ち分
