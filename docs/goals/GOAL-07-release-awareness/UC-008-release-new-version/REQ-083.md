# REQ-083

> ホーム画面またはブラウザで動くアプリの問い合わせで Web 配信元に新しい版があると分かったとき、システムは占う人の操作なしに新しい版へ入れ替わる。

## 検証方針

- **分割クラス**:
  - `#swap-without-prompt` — 入れ替えを即時に行う指定で仕組みを登録し、新しい版が見つかっても占う人に確認を求める表示を出さない
- **尽きている根拠**: アプリ側から観測できる「操作なしに入れ替わる」の現れは、即時の指定での登録と、確認を求める表示が無いことだけで、入れ替えの実行は仕組みの側が行う。
- **検証しない**: 実際に新しい版へ入れ替わること（待機中の版の有効化と開き直し）。本物のブラウザの保持の仕組みでしか起きないため。占いの途中で新しい版が見つかった場合（UC-008 の状態表で `?`、振る舞いが決まっていない）。
