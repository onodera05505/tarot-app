# REQ-081

> 運営者が出した版が検査のいずれかに落ちた場合、システムはその版を Web 配信元へ配らず、配信元は前の版のままである。

## 検証方針

- **分割クラス**:
  - `#test-failure-blocks-deploy` — テストが落ちたとき、配る手順に進まない順序で宣言されている
  - `#build-failure-blocks-deploy` — 本番ビルドが落ちたとき、配る手順に進まない順序で宣言されている
- **尽きている根拠**: 検査は「テスト → ビルド → 配る」の順の 2 段（`docs/検査と門.md` #13）で、「いずれかに落ちる」はそのどちらが落ちるかの 2 通りで尽きる。
- **検証しない**: 落ちた後に配信元が実際に前の版のままであること。配信の経路でしか確かめられず、途中で止まることは CI 自身の振る舞いに依るため。
- **参照先**: 未配置（この要件を観測する既存のテストは無い）
