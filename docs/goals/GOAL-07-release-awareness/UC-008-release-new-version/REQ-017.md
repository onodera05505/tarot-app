# REQ-017

> ネイティブのアプリとして動いている間、システムは Web 配信元へ問い合わせず、自動更新もせず、同梱の版のまま動く。

## 検証方針

- **分割クラス**:
  - `#native-skips-registration` — ネイティブのアプリとして動いているとき、保持と入れ替えの仕組みを登録しない（契約の registerSW を呼ばない）
  - `#native-no-query-on-triggers` — ネイティブのアプリとして動いているとき、開く・前面に戻す・開いたまま一定時間が経つのいずれでも Web 配信元に問い合わせない（契約の registrationUpdate を呼ばない）
- **尽きている根拠**: 「問い合わせない」「自動更新しない」は、仕組みを登録しないこと（入れ替えの入口が無い）と、問い合わせのきっかけ（UC-008 の状態表の 3 つのイベント）のどれでも問い合わせないことで尽きる。「同梱の版のまま動く」は、この 2 つが成り立てば入れ替えが起きないことの帰結。
- **検証しない**: ストアを通した版の入れ替え（ストアと端末の OS の責務）。ネイティブの実行環境での実際の挙動（実機でしか確かめられないため）。
- **参照先**: 未配置（この要件を観測する既存のテストは無い）
