- **分割クラス**:

- **尽きている根拠**: 状態は「トップを示している」の 1 つで、UC-008 の状態表はどの版の状態でも REQ-085 を指す。識別子は端末の状態に依らずビルドで決まるので、端末の状態で分割しない。
- **検証しない**: 示された識別子が実際に配信中のビルドと一致すること（配信の経路を通してしか確かめられないため）。識別子の書式（要件に無い）。
