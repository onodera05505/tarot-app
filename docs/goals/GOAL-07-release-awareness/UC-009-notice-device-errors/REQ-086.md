# REQ-086

> 画面の描画中に予期しないエラーが起きた場合、システムは占う人に、エラーが起きたことと、トップへ戻る手段を示す。

## 検証方針

- **分割クラス**:
  - `#fallback-with-reporter` — 本番の版で報告先があるとき、描画中に予期しないエラーが起きると、エラーが起きたこととトップへ戻る手段が示される
  - `#fallback-without-reporter` — 報告先が無いとき（開発中の版、または報告先を設定していない本番の版）でも、描画中のエラーで同じ表示が示される
- **尽きている根拠**: UC-009 の状態表で REQ-086 は「本番の版・報告先あり」と「報告先なし」の 2 行に現れ、表示は報告の有無に依らない。この 2 行で端末の状態が尽きる（「エラーの表示中」の行は `?`）。
- **検証しない**: エラーの表示中に描画中のエラーがさらに起きた場合（状態表で `?`、振る舞いが決まっていない）。表示の見た目（本物のブラウザでしか確かめられないため）。
- **参照先**: 未配置（この要件を観測する既存のテストは無い）
