# REQ-129

> 本番の版で報告先が設定されている間、システムはエラー監視サービスへの報告に稼働中の版のビルド識別子を添える。

- **分割クラス**:
  - `#release-is-build-id` — 本番の版で報告先が設定されているとき、報告を始める設定の release に、稼働中の版のビルド識別子（用語集: `__APP_VERSION__`）を空でない文字列で渡す
- **尽きている根拠**: 文が添えると言う対象はビルド識別子の 1 つで、契約の init でも release は必須かつ空でない文字列の 1 項目。状態は「本番の版・報告先あり」の 1 行（UC-009 の状態表の「アプリを開く」）で、報告先なしの側は報告そのものを始めないので REQ-088 が持つ。「運営者が報告を見る」の列は、添えた識別子を外部サービスで見る側で、アプリ側の観測は始めるときの設定まで。
- **検証しない**: 報告に実際に識別子が付いてエラー監視サービスで版を特定できること（外部サービスを通してしか確かめられない。`docs/verification/GLOBAL.md` の配信・エラー監視の行）。識別子の書式（要件に無い。REQ-085 と同じ）。
