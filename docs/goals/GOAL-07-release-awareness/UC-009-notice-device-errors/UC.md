# UC-009 端末で起きたエラーを知る

## 概要

占う人の端末で予期しないエラーが起きたとき、システムが占う人に戻り道を示しつつエラー監視サービスへ報告し、運営者がその報告を見てエラーを知る。

## 事前条件

- 端末で動いているのが本番の版で、報告先が設定されている
- 適用される業務規則: なし（報告するのが報告先の設定された本番の版だけである決まりはこの UC の中で閉じ、表の行が持つ）

## 主シナリオ

1. システムが占う人の端末で、画面の描画中に予期しないエラーを捉える
2. システムが占う人に、エラーが起きたことと、トップへ戻る手段を示す
3. システムがエラーをエラー監視サービスへ報告する
4. 運営者がエラー監視サービスでエラーの報告を見る
