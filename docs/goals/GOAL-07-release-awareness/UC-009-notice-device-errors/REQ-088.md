# REQ-088

> 開発中の版であるか報告先が設定されていない間、システムは端末で起きたエラーをエラー監視サービスへ報告しない。

## 検証方針

- **分割クラス**:
  - `#dev-build-no-report` — 開発中の版では、報告先の有無に依らず、エラーをエラー監視サービスへ報告しない（契約の init が呼ばれない）
  - `#prod-without-reporter-no-report` — 本番の版でも報告先が設定されていなければ、エラーを報告しない
- **尽きている根拠**: 条件は「開発中の版である」か「報告先が設定されていない」かの論理和で、本番・報告先ありの残りの 1 区画は REQ-087 が持つ。開発中の版は報告先の有無を問わないので 1 クラスにまとめる。
- **検証しない**: 無し（報告しないことは、報告を始める操作が呼ばれないことで何も起動せずに観測できる）。
- **参照先**: `frontend/tests/UC-009-error-report-init.test.ts` の describe「アプリを開いたときのエラー監視サービスへの報告の始め方（UC-009）」の「報告先なし」
