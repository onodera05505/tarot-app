# REQ-123

> 本番の版で報告先が設定されている間、システムはエラー監視サービスへの報告を、利用者の情報を既定で送る設定を有効にして行う。

## 検証方針

- **分割クラス**:
  - `#default-user-info-enabled` — 本番の版で報告先が設定されているとき、利用者の情報を既定で送る設定を有効にして報告を始める（契約の init の該当の設定）
- **尽きている根拠**: 文が言う設定は 1 つで、値は有効の 1 通り。状態は「本番の版・報告先あり」の 1 行（UC-009 の状態表の「アプリを開く」）で、報告先なしの側は報告そのものを始めないので REQ-088 が持つ。
- **検証しない**: この設定で実際にどの情報がエラー監視サービスへ送られるか。送る中身は SDK とエラー監視サービスが決め、配信した本番の版と外部サービスを通してしか確かめられないため（`docs/verification/GLOBAL.md` の配信・エラー監視の行）。
- **参照先**: 未配置（この要件を観測する既存のテストは無い。アプリの入口を起動するテストは、テストの設定がビルド時にだけ存在する保持の仕組みのモジュールを解決できず、設定を足すまで書けない）
