# REQ-011

> 占う人が全削除を選んで確認に承諾したとき、システムは、端末から消せなかった場合を除き、占い履歴をすべて端末から消し、履歴がないことを示してそこから占いを始められるようにする。

- **分割クラス**:
  - `#accept-clears-all` — 端末から消せたとき（端末が消去を受け付ける前提）、記録がある状態で全削除を選んで確認に承諾すると、端末の占い履歴も示している一覧もすべて消え、履歴がないことが示されて占いを始められる
- **尽きている根拠**: 全削除の承諾は記録あり（上限件数未満・上限件数）の状態でだけ起きうる（空と読めないときは操作を出さない）。件数によって振る舞いは変わらないので 1 クラス。「端末から消せなかった場合」はこの要件の除外条件で、REQ-126 が持つ
- **検証しない**: 端末から消せなかったとき（REQ-126 の分割クラスで検証する）。空・読めないときの承諾（全削除の操作を出さないので起きない。REQ-007・REQ-009 の側で見る）。全削除の後に占いを始めたときの占い状態の初期化（履歴なしの表示から始める振る舞いは同じ画面なので REQ-007 の `#start-discards-previous` が見る）
