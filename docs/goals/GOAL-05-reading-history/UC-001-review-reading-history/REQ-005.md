# REQ-005

> 詳しく占うで結果の確定が起きたとき、システムはその占い結果（カード・正逆・キーワード）とその日時にカテゴリ名を添えて、占う人の操作なしに占い履歴の先頭へ加えて端末に記録する。

## 検証方針

- **分割クラス**:
  - `#category-attached` — 詳しく占うの結果の確定で、カード・正逆・キーワード・日時にカテゴリ名が添えられて先頭に記録される
  - `#recorded-on-confirmation` — 詳しく占うの結果の確定だけで、占う人の操作なしに記録が起きる
- **尽きている根拠**: 通常占いとの違いはカテゴリ名が添わることだけで、先頭への追加の振る舞いは REQ-001 と共通。記録の中身と記録の起こり方を分ける理由は REQ-001 と同じ
- **検証しない**: 無料版では詳しく占うそのものを出さない（BR-005）ので、無料版の構成ではこの要件を起こせない。機能フラグ有効の構成でだけ検証する
- **参照先**: 既存のテスト無し（カテゴリ名つきの記録は `frontend/tests/components/HistoryPage.test.tsx` が一覧の準備として使うが、記録そのものは観測していない）
