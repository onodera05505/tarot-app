# REQ-007

> 占い履歴が空である間、占う人が占い履歴を開くと、システムは履歴がないことを示し、そこから占いを始められるようにする。

- **分割クラス**:
  - `#empty-message` — 占い履歴が空のとき、開くと履歴がないことが示され、カードの項目は示されない
  - `#start-from-empty` — 占い履歴が空のとき、示された画面から占いを始められる
- **尽きている根拠**: 空の占い履歴を開いたときに求められる観測は「履歴がないことを示す」と「占いを始められる」の 2 つで、片方だけが壊れうるので分ける。読めない記録内容による空は REQ-009、全削除の後の空は REQ-011 に分けてある
- **検証しない**: 履歴がないことを示す文言の言い回し（画面の文言は用語集と画面の側が持つため）
