# UC-001 占い履歴を振り返る

## 概要

占う人が、結果の確定のたびに端末へ記録された占い履歴を、後から記録したものを先にして見返し、要らなくなったら全削除する。

## 事前条件

- 占い履歴はその端末の中にだけあり、結果の確定のたびにシステムが自動で記録している（記録は占いの側で起き、占う人の操作は要らない）
- 適用される業務規則: BR-004、BR-003、BR-005

## 主シナリオ

1. 占う人が通常占いまたは詳しく占うを行い、結果の確定を迎える
2. システムが、端末に記録できるかぎり、占い結果（カード・正逆・キーワード）と日時を占い履歴の先頭に記録する。カテゴリとすべての回答がそろった詳しく占うではカテゴリ名を添える → BR-004
3. 占う人が占い履歴を開く
4. システムが占い履歴を、後から記録したものを先にして一覧で示す（日時・カード・正逆・キーワード、カテゴリ名を添えて記録したものはカテゴリ名つき） → BR-003
5. 占う人が一件を選ぶ
6. システムがそのカードのカード解説を、記録した正逆で開く
7. 占う人が占い履歴へ戻り、全削除を選んで確認に承諾する
8. システムが占い履歴をすべて消し、履歴がないことを示して占いを始められるようにする

## 事後条件

- 成功時: 占う人が占い履歴を開くと、履歴がないことが示される
- 失敗時: いかなる状態変更も残っていない（部分適用なし）。端末へ書けなかった結果の確定では、占い履歴は確定の前のまま
