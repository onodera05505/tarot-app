# REQ-049

> 詳しく占うの占い結果を示すとき、カテゴリの文章を読み込めていれば、システムはカード・正逆・キーワードに加えて、カテゴリ名と、引いたカードと正逆とカテゴリで決まるベース解釈と、選んだ選択肢と引いたカードの組に回答別アドバイスがある回答ごとにその回答別アドバイスを示し、解説文は示さない。

## 検証方針

- **分割クラス**:
  - `#upright-base` — 正位置で、カテゴリ名・正位置のベース解釈・回答ごとの回答別アドバイスが示され、解説文は示されない
  - `#reversed-base` — 逆位置で、カテゴリ名・逆位置のベース解釈・回答ごとの回答別アドバイスが示され、解説文は示されない
- **尽きている根拠**: ベース解釈は正逆で分かれる。カテゴリ・カード・選択肢の組は同じ規則で引かれる。回答別アドバイスが無い回答は REQ-051、カテゴリの文章を読み込めていない間は REQ-050 が持つ
- **境界の扱い**: カード・正逆・キーワードの表示は通常占いと共通（UC-006 の要件が持つ）
- **検証しない**: 全カテゴリ × 全カード × 全選択肢の組（文章の揃いは UC-010 の検査が持つ）
