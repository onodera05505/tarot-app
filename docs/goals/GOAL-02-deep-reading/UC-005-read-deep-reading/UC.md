# UC-005 詳しく占う

## 概要

占う人がカテゴリを選び質問に答えたうえで儀式を経てカードを引き、カテゴリと回答に沿った文章で占い結果を読む。無料版では詳しく占うそのものが現れない（表の「無料版」の行）。

## 事前条件

- 機能フラグが有効である（無効＝無料版のときの振る舞いは表の「無料版」の行が持つ）
- 適用される業務規則: BR-005、BR-002、BR-001、BR-004

## 主シナリオ

1. 占う人がトップで詳しく占うを始める。 → BR-002
2. システムがカテゴリを示す。
3. 占う人がカテゴリを選ぶ。
4. システムがそのカテゴリの質問を 1 つずつ示す。
5. 占う人が各質問で選択肢を選び、すべての質問に答える。
6. システムがカテゴリとすべての質問の回答を持ち込んで儀式を始める。 → BR-002
7. 占う人が儀式を進め、ストップで結果の確定が起きる。 → BR-001
8. システムが占い結果をカテゴリ名を添えて占い履歴に記録する。 → BR-004
9. システムが占い結果として、カード・正逆・キーワードに加えて、カテゴリ、引いたカードと正逆とカテゴリで決まるベース解釈、回答ごとの回答別アドバイスを示す。

## 事後条件

- 成功時: 占う人が、選んだカテゴリと、引いたカード・正逆に応じたベース解釈と、回答ごとの回答別アドバイス（回答別アドバイスを持たないカテゴリでは回答ごとの回答別補足）を占い結果として読めている。占い履歴にカテゴリ名つきの占い結果が 1 件増えている。
- 失敗時（結果の確定より前に終えた場合。抽選の失敗を含む）: 占い履歴には何も増えていない。質問の途中で終えた場合は、その回の回答は残っていない。儀式へ持ち込んだあとで終えた場合は、持ち込んだカテゴリと回答が次の占い状態の初期化まで残る。 → BR-002
- 失敗時（結果の確定の後にカテゴリの文章を読み込めなかった場合）: 占い履歴にはカテゴリ名つきの占い結果が 1 件増えており、占う人はその占い結果を解説文で読めている。
