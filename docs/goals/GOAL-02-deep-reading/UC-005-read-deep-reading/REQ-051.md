# REQ-051

> 詳しく占うの占い結果を示すとき、カテゴリの文章を読み込めていて、選んだ選択肢と引いたカードの組に回答別アドバイスが無い回答がある場合、システムはその回答について、回答別アドバイスの代わりにその選択肢の回答別補足を示す。

## 検証方針

- **分割クラス**:
  - `#supplement-when-no-advice` — 引いたカードにどの回答の回答別アドバイスも無いと、回答ごとにその選択肢の回答別補足が示される
  - `#supplement-only-for-answers-without-advice` — 回答別アドバイスがある回答と無い回答が混ざると、ある回答には回答別アドバイス、無い回答にはその選択肢の回答別補足が示される
- **尽きている根拠**: 回答ごとに「回答別アドバイスが有る／無い」の 2 値で、すべて有る場合は REQ-049、すべて無い場合と混ざる場合がこの 2 クラス
- **境界の扱い**: 現在のカテゴリの文章はすべて回答別アドバイスを持つので、回答別補足を持つ文章は、読み込みを差し替えたテスト専用の文章で作る
- **検証しない**: 回答別アドバイスも回答別補足も無い回答（生成と検査が文章の欠けを禁じる — UC-010 の要件 — ので外から起こせない）。回答別アドバイスがある回答で回答別補足を併せて示さないこと（文が一意に定めていない）
- **参照先**: `frontend/tests/components/UC-005-category-loading.test.tsx::詳しく占う: 回答別アドバイスが無い回答には回答別補足を示す`
