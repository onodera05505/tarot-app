# REQ-035

> 無料版である間、システムは詳しく占うを始める入口を示さず、詳しく占うの予告表示もしない。

## 検証方針

- **分割クラス**:
  - `#no-entry-on-top` — 無料版のトップに詳しく占うの入口もその語も現れない
  - `#no-teaser-on-top` — 無料版のトップに予告表示の語が現れない
  - `#no-teaser-on-result` — 無料版の占い結果に予告表示の語が現れない（BR-005 の画面の列挙）
  - `#no-teaser-on-history` — 無料版の占い履歴に予告表示の語が現れない（BR-005 の画面の列挙）
  - `#entry-shown-when-enabled` — 機能フラグが有効なら入口が現れる（非表示が機能フラグだけで決まることの対照）
- **尽きている根拠**: 状態（無料版／機能フラグ有効）× 示すもの（入口／予告表示）× 予告表示を置きうる画面（BR-005 のトップ・占い結果・占い履歴）で尽きる
- **境界の扱い**: 予告表示とみなす語の並びは `FreeRelease.test.tsx` の判定語が持つ（仕様 §3.3 の並びとの差は OQ-17）
- **検証しない**: Web とネイティブのアプリで同じ構成であること（同一ビルドのため。ネイティブの実機でしか確かめられない）
- **参照先**: `frontend/tests/components/FreeRelease.test.tsx::無料版のトップ画面（§3.3 / §5.2）`、`frontend/tests/components/FreeRelease.test.tsx::無料版のルーティング（§3.3 / §5.1）`、`frontend/tests/components/FreeRelease.enabled.test.tsx::フラグ有効時のトップ画面（§5.2）`
