# REQ-043

> 選んだカテゴリの文章を読み込んでいる間、システムはどのカテゴリの選択も受け付けない（読み込んでいるカテゴリをもう一度選ぶ場合を含む）。

## 検証方針

- **分割クラス**:
  - `#reject-other-while-loading` — 読み込んでいる間に別のカテゴリを選んでも受け付けず、先に選んだカテゴリの質問が示される
  - `#reject-same-while-loading` — 読み込んでいる間に同じカテゴリをもう一度選んでも受け付けない
- **尽きている根拠**: 読み込んでいる間に選べるカテゴリは、読み込んでいるカテゴリか、それ以外かの 2 つ（戻るは REQ-041）
- **境界の扱い**: 「受け付けない」は、カテゴリの文章の読み込みが新たに始まらないことで見る。読み込んでいる間にカテゴリを選べない形で示す（押せない・示さない）場合も受け付けないに含める
- **検証しない**: 無し
