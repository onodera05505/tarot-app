# REQ-108

> 占う人がトップの入口を経ずに詳しく占うへ直接到達したとき、システムは前の占い結果と詳しく占うの回答を引き継がずに占い状態を idle にし、どの質問にも回答が無い状態でカテゴリを示す。

- **分割クラス**:
  - `#direct-reach` — 機能フラグが有効なときに詳しく占うへ直接到達すると、トップへ移されずにカテゴリが示される
  - `#discard-previous` — 前の占い結果と、前に儀式へ持ち込んだカテゴリと回答が残っている状態で直接到達すると、占い状態が idle になり、どれも引き継がれない（通常占いの状態に戻る）
- **尽きている根拠**: 直接到達の時点で前の回の残り（占い結果・持ち込んだカテゴリと回答）が無いか有るかの 2 値で尽きる。有る側は、表で REQ-108 が当たる行のうち残りを持ちうるもの（儀式中・儀式の外・占い結果の各占い状態）を占い状態 × 持ち込みの有無の組で代表させ、どの行でも同じ文で振る舞いが分かれない
- **境界の扱い**: 無料版での直接到達は REQ-036 が持つ。トップの入口から始める場合の初期化は REQ-038 が持つ（文は同じで、入口の有無だけが違う）
- **検証しない**: ブラウザの戻る・進むそのもの（jsdom のテストはアドレスの指定で到達し、到達の仕方で振る舞いが分かれる文ではない。本物のブラウザの履歴の動きは実経路でしか確かめられない — docs/verification/GLOBAL.md のシナリオテストの行）。直接到達のあとに前の抽選が完了・失敗する場合（UC.md の表の並行性の行で未決）。前の回に質問の途中まで答えた回答が残っている場合（REQ-038 と同じく外から作れない）
