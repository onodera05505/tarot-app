# REQ-108

> 占う人がトップの入口を経ずに詳しく占うへ直接到達したとき、システムはどの質問にも回答が無い状態でカテゴリを示し、その時点の占い状態と、前の占い結果と、前に儀式へ持ち込んだカテゴリと回答を変えない。

- **分割クラス**:
  - `#direct-reach` — 機能フラグが有効なときに詳しく占うへ直接到達すると、トップへ移されずにカテゴリが示される
  - `#keeps-previous-state` — 前の占い結果と、前に儀式へ持ち込んだカテゴリと回答が残っている状態で直接到達しても、占い状態もそれらも変わらない
- **尽きている根拠**: 直接到達の時点で前の回の残りが無いか有るかの 2 値で尽きる。表の各行（カテゴリ選択中から占い結果まで）からの直接到達は、どの行でも同じ文で、行によって振る舞いが分かれない
- **境界の扱い**: 無料版での直接到達は REQ-036 が持つ
- **検証しない**: ブラウザの戻る・進むによる直接到達と、質問の途中・儀式中・占い結果からの直接到達（jsdom のテストはアドレスの指定で到達する。本物のブラウザの履歴の動きは実経路でしか確かめられない — docs/verification/GLOBAL.md のシナリオテストの行）
- **参照先**: `frontend/tests/components/DeepFlow.test.tsx::詳しく占う: カテゴリ選択と質問フロー（§5.7 1-2）`、`frontend/tests/components/FreeRelease.enabled.test.tsx::フラグ有効時のルーティング（§5.1 / §5.7）`、`frontend/tests/components/UC-005-entry-and-ritual.test.tsx::詳しく占う: トップの入口を経ない直接到達`
