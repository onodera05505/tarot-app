# REQ-038

> 占う人がトップで詳しく占うを始めたとき、システムは前の占い結果と詳しく占うの回答を引き継がずに占い状態を idle にし、どの質問にも回答が無い状態でカテゴリを示す。

## 検証方針

- **分割クラス**:
  - `#start-from-entry` — トップの入口から始めるとカテゴリが示される
  - `#discard-previous` — 前の占い結果と、前に儀式へ持ち込んだカテゴリと回答が残っていても、始めた時点で占い状態が idle になり、どれも引き継がれない
- **尽きている根拠**: 始めるときに前の回の残り（占い結果・持ち込んだカテゴリと回答）が有るか無いかの 2 値で尽きる。入口を経ない到達は REQ-108 が持つ
- **検証しない**: 前の回に質問の途中まで答えた回答が残っている場合（質問の途中の回答は、詳しく占うを終えた時点で残らない — REQ-041・REQ-047 と UC.md の事後条件 — ので、残った状態を外から作れない）
- **参照先**: `frontend/tests/components/UC-005-entry-and-ritual.test.tsx::詳しく占う: トップの入口から始める`
