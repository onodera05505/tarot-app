# REQ-038

> 占う人がトップで詳しく占うを始めたとき、システムは前の占い結果と詳しく占うの回答を引き継がずに占い状態を idle にし、どの質問にも回答が無い状態でカテゴリを示す。

- **分割クラス**:
  - `#start-from-entry` — トップの入口から始めるとカテゴリが示される
  - `#direct-reach` — 詳しく占うへ直接到達するとカテゴリが示される（機能フラグ有効時）
  - `#no-previous-answers` — 前回の詳しく占うの回答が残っていても、どの質問にも回答が無い状態で始まる
- **尽きている根拠**: 始め方（入口／直接到達）× 前回の回答の有無で尽きる
- **検証しない**: 無し
