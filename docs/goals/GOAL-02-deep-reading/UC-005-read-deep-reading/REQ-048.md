# REQ-048

> 詳しく占うの儀式で結果の確定が起きたとき、システムは回答に左右されない抽選でカードと正逆を決める。

## 検証方針

- **分割クラス**:
  - `#keep-context-through-stop` — カテゴリと回答を持ち込んだ儀式で結果の確定が起きるとカードと正逆が決まり、持ち込んだカテゴリと回答は失われない
  - `#draw-independent-of-answers` — 乱数の出方が同じなら、回答やカテゴリが違っても同じカードと正逆が決まる
- **尽きている根拠**: 結果の確定で起きること（持ち込んだまま抽選が成り立つこと）と、抽選が回答に左右されないことの 2 つで尽きる
- **境界の扱い**: 抽選の一様さ・正逆の出る割合・抽選の失敗は UC-006 の要件（REQ-057）が持つ。占い履歴へカテゴリ名を添えて記録することは REQ-005（UC-001 の要件）が持つ。`#keep-context-through-stop` の「持ち込んだカテゴリと回答は失われない」は、表の「持ち込んでいる」の定義（占い状態の初期化を経ずに残っている）と BR-002（儀式に入ること自体では初期化しない）による
- **検証しない**: 回答の全通り × 乱数の出方の全通り（左右されないことは、乱数の出方を固定した数点で回答とカテゴリを変えて見る）。乱数そのものの偏り（統計でしか見られず、UC-006 の REQ-057 `#random` が粗く見る）
