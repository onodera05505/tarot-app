# REQ-039

> カテゴリを示していて、どのカテゴリの文章も読み込んでいる最中でないときに占う人がカテゴリを選んだとき、システムはそのカテゴリの文章を読み込み、読み込めたらそのカテゴリの最初の質問とその選択肢を示す。

## 検証方針

- **分割クラス**:
  - `#first-question` — まだどのカテゴリの文章も読み込んだことがないときにカテゴリを選ぶと、読み込めた文章からそのカテゴリの最初の質問とその選択肢がすべて示される
  - `#select-after-earlier-load` — 前の読み込みが済んだあと（読み込めて最初の質問から戻った・読み込めなかった）に示し直したカテゴリから選んでも、選んだカテゴリの最初の質問とその選択肢が示される
- **尽きている根拠**: 条件「読み込んでいる最中でない」に当たるのは、まだ一度も読み込んでいないときと、前の読み込みが済んだ（成功・失敗）あとの 2 つ。読み込みが成功した場合がこの要件で、失敗は REQ-040、読み込んでいる最中の選択は REQ-043 が持つ
- **境界の扱い**: `#select-after-earlier-load` は、前の読み込みが成功で済んだ側（REQ-047 でカテゴリを示し直したあと）と、失敗で済んだ側（REQ-040 でカテゴリを選び直せる状態にとどまったあと）の両方を見る
- **検証しない**: カテゴリごとの差（カテゴリの文章の形は UC-010 の検査が揃える）。同じカテゴリの文章を二度目に選んだときに読み込みをやり直すかどうか（外から観測できるのは最初の質問が示されることだけで、要件の文も読み込みの回数を定めていない）
