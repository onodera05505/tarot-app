# UC-003 本日の一枚を開く

## 概要

占う人が、その日の本日の一枚を開封してカードと正逆を受け取り、そのカードのカード解説へ進む。開封済みの本日の一枚は、同じ日のうちは引き直さない。

## 事前条件

- その日の本日の一枚が未開封である
- 適用される業務規則: BR-001、BR-004、BR-003

## 主シナリオ

1. 占う人が未開封の本日の一枚を選ぶ
2. システムがカードと正逆を抽選する → BR-001
3. システムがその日の開封として記録し、本日の一枚をカード・カード名・正逆とともに開封済みで示す → BR-003
4. 占う人が開封済みの本日の一枚を選ぶ
5. システムがそのカードのカード解説を、本日の一枚の正逆を初期表示の正逆として示す

## 事後条件

- 成功時: その日の本日の一枚が開封済みで、同じ日に再び示してもその日の開封として記録されているカードと正逆であり、そのカードのカード解説を読める
- 失敗時: いかなる状態変更も残っていない（部分適用なし）。本日の一枚は未開封のまま
