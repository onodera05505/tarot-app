# REQ-018

> 占う人が未開封の本日の一枚を選んだとき、システムは抽選したカードと正逆をその日の開封として記録し、本日の一枚をそのカード・カード名・正逆とともに開封済みで示す。

## 検証方針

- **分割クラス**:
  - `#records-today` — 未開封の本日の一枚を選ぶと、抽選したカードと正逆が端末の現地日付のその日の開封として記録される
  - `#shows-opened` — 未開封の本日の一枚を選ぶと、本日の一枚がそのカード・カード名・正逆とともに開封済みで示される
- **尽きている根拠**: 選んだ結果の観測は「記録」と「示し方」の 2 つで、片方だけが壊れうるので分ける。抽選の結果（どのカード・どちらの正逆か）は BR-001 によりランダムで、値ではなく「記録したものと示したものが一致すること」を見る
- **検証しない**: 抽選の分布（BR-001 の抽選の側の検証であり、この要件の振る舞いではないため）。開封の演出（アニメーション・効果音。実機でしか確かめられないため）
