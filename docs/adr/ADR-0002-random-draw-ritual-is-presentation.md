# ADR-0002 占い結果は完全ランダムに決め、儀式の操作は演出にとどめる

## Context

儀式では占う人が山の順番や左右を選ぶ。その選択を占い結果の正逆に反映させる実装（左右選択で正逆を決める）が一度入ったが、2026-05-02 のコミット 24efef6 で撤回された。コミットには「ユーザー依頼により左右選択は儀式演出のみ、正逆はランダム維持」とある。`history/2026-08-21.md` の 2. が「意図的。退行ではない」と確認している。詳しく占うを足したとき（2026-08-21）も、質問の回答は抽選に影響させないと決めた。BR-001。

## Decision

カードと正逆は、結果の確定の時点の抽選だけで決める。儀式の操作（山の順番・左右選択）と詳しく占うの回答は、占い結果に影響させない。
担保: `ShufflePage.test.tsx` の「左右選択が正逆を書き換えない」と、抽選の単体テスト。

## Consequences

- 良い面: 結果の公平さを説明できる。儀式を足したり変えたりしても結果の決まり方が変わらない。
- 悪い面: 「自分で選んだ」感覚と結果が結び付かない。選択が結果に効くと期待する人には、演出であることが伝わらない。

## 却下した選択肢

- **左右選択で正逆を決める**: 一度実装したが、本人の依頼で撤回した（コミット 24efef6）。正逆を占う人の操作で決めると、結果がランダムでなくなる。
