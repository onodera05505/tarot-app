# ADR-0006 ネイティブのアプリの中では自動更新の仕組みを動かさない

## Context

2026-09-03 に Capacitor で Android のプロジェクトを作った（`history/2026-09-03.md` の 2.）。ネイティブのアプリは内容を同梱し、版はストア経由で入れ替わる。そこでブラウザ向けの自動更新（ADR-0003）も動くと、二重に入れ替わる。BR-006、REQ-017。

## Decision

ネイティブのアプリの中では、新しい版の問い合わせも入れ替えもしない。判定はアプリの入口の 1 箇所に置く。
担保: 構造的な門は無い（実機で確かめる項目。`docs/検査と門.md` の 8 行目）。

## Consequences

- 良い面: ストアの版と中身が一致する。入れ替えの競合が起きない。
- 悪い面: 不具合を直しても、ストアの審査と利用者の更新を待つ。Web とネイティブで動いている版がずれる期間ができる。

## 却下した選択肢

- **記録なし**: 当時の比較は記録されていない（移行時に付した記録）
