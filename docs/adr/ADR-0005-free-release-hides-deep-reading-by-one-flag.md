# ADR-0005 無料版では詳しく占うを 1 箇所の機能フラグで隠す

## Context

初回のストア申請を無料・広告なしで行うにあたり、本人が「機能は意図的に今より減らして出したい」と決めた（`history/2026-09-02.md` の 6.）。3 点を選択肢から採否した: 詳しく占うを丸ごと外す／Web も同じ制限にする／予告表示なしで完全に隠す。BR-005、REQ-035〜037。

## Decision

無料版では詳しく占うを出さない（入口を出さない・直接到達はトップへ・結果は通常占いの表示・予告表示もしない）。データ・コード・テストは残し、切り替えは機能フラグ 1 箇所で行う。Web とネイティブで同じにする。
担保: `FreeRelease.test.tsx`・`FreeRelease.enabled.test.tsx`、フラグの置き場を 1 箇所に固定する `features-flag.test.ts`。

## Consequences

- 良い面: 買い切りで開放する価値を残せる。課金を入れるとき、フラグを購入状態に置き換えるだけで済む。
- 悪い面: 完成している機能を利用者が使えない。出していないコードとテストを保守し続ける。予告表示とみなす語の並びが仕様とテストに分かれている（OQ-17・OQ-30 の 2）。

## 却下した選択肢

- **詳しく占うの一部だけ残す**: 採らなかった（本人が「丸ごと外す」を選択）。
- **Web 版だけ全機能を残す**: Web で無料のままだと買い切りの価値が薄れる。
- **「準備中」などの予告を出す**: 審査で未完成と見なされる余地を作らない。
