# ADR-0004 詳しく占うの文章は、ベース解釈と回答別アドバイスの合成で作る

## Context

詳しく占う（カテゴリ × 質問 3 問）の結果を全ての組み合わせで書くと、約 3,600 本になり執筆と品質管理が破綻する（`history/2026-08-21.md` の 9.）。最初は「ベース解釈 + カードに連動しない回答別補足」で始めたが、実機で読んだ本人から「抽象的でピンとこない」と指摘があり、同日に「カード × 選択肢」の回答別アドバイスへ改めた（同 13.、仕様 v3.2）。

## Decision

結果の文章は、カードと正逆で決まるベース解釈に、カードと選択肢の組で決まる回答別アドバイスを足して作る。全ての組み合わせの文章は書かない。編集元の書式と字数、第一文のジャンル語は、生成と検査で確かめる（REQ-092〜094）。

## Consequences

- 良い面: 書く量が現実的になり、カテゴリを足せる。カードと悩みの両方に触れた文章になる。
- 悪い面: 3 問の回答の組み合わせに固有の文章にはならない。アドバイスどうしが独立なので、並べたときに重なりや食い違いが出うる。

## 却下した選択肢

- **全ての組み合わせを書く**: 約 3,600 本になり、執筆と品質管理が破綻する。
- **カードに連動しない回答別補足だけにする**: 一度実装したが、本人が「抽象的でピンとこない」と退けた（2026-08-21）。旧構造として代替表示だけが残っている（REQ-051）。
