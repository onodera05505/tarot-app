# ADR-0003 新しい版は自動で入れ替え、占う人に手動の更新をさせない

## Context

2026-08-21、不具合を直して配った後も本人の端末で古い版が出続けた。本人の要望は「ユーザーに手動更新をさせる仕組みは駄目だ」（`history/2026-08-21.md` の 12.）。原因は特定できなかった（中央の報告書 77）。REQ-082〜084。

## Decision

ブラウザ・ホーム画面で動くときは、開いたとき・前面に戻したとき・一定時間ごとに新しい版を問い合わせ、あれば占う人の操作なしに入れ替える。稼働中の版はトップにビルド識別子で示す（REQ-085）。
担保: 構造的な門は無い（自動更新とビルド識別子を見るテストが無い。OPEN-QUESTIONS OQ-31 の 4）。

## Consequences

- 良い面: 直した版が利用者に届くまでの手間が無い。ビルド識別子で、どの版が動いているかを確かめられる。
- 悪い面: 占いの途中でも入れ替わり、途中の占いが消える（OQ-28 の 1）。入れ替えの瞬間に画面が読み込み直される。

## 却下した選択肢

- **手動で更新してもらう（案内を出す）**: 本人が明確に退けた（2026-08-21）。
