# ADR-0009 ソースの層は画面から下へ向かってだけ参照する

## Context

ソースは 画面（pages）・部品（components）・状態（store）・処理（lib）・データ（data）に分かれている。2026-10-03 の時点で、下の層が上の層を参照している箇所は 0 件だった（層ごとの import を数えた）。この向きを決めた記録は無い。

## Decision

処理とデータの層は、画面・部品・状態を参照しない。状態は画面と部品を参照しない。部品は画面を参照しない。
担保: `traceconfig.json` の `layering` と trace-check の C6。

## Consequences

- 良い面: 処理とデータを画面なしでテストできる。向きが崩れたら検査で分かる。
- 悪い面: 処理とデータは互いに参照し合っており（抽選がカードの内容を読み、カードの内容が型を読む）、この 2 層の間の向きは決めていない。C6 が見るのは import の書き方だけで、動的な読み込みは見ない。

## 却下した選択肢

- **記録なし**: 当時の比較は記録されていない（移行時に付した記録）
